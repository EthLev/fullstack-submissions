# Fullstack Submissions

Exercise solutions for the [Full Stack Open](https://fullstackopen.com/en/) course.

## Structure

Each part/exercise lives in its own folder as an independent npm project (own `package.json`, own dependencies) rather than one shared app, since most exercises are separate small React applications.


## Running an exercise

```bash
cd part1/<exercise-name>
npm install
npm run dev
```
